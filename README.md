# Walidator IFC MVP

Lokalna aplikacja webowa do kontroli pojedynczego modelu IFC (IFC2X3).

## Wymagania

- Python 3.11

## Instalacja

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Uruchomienie

```bash
streamlit run app.py
```

## Testy

```bash
pytest
```
